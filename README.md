# m1ersitioweb.github.io
Costa Viva es una página web inspirada en la cultura costeña colombiana, donde se destacan la música vallenata, la gastronomía típica, los paisajes tropicales y las tradiciones del Caribe colombiano.  Este sitio busca mostrar la alegría, el sabor y la riqueza cultural de la región Caribe a través de imágenes, música, videos y contenido interactivo.
